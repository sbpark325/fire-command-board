현장지휘 보드 개인정보처리방침

시행일: 2026년 8월 14일

"현장지휘 보드"(이하 "앱")는 소방 현장 지휘 활동 지원을 위한 도구입니다. 본 방침은 앱이 처리하는 정보와 그 방식을 설명합니다.

1. 수집·처리하는 정보

  • 보드 데이터: 사용자가 작성한 사건명, 출동대 배치, 그림·메모, 체크리스트, 시간별 기록 등은 기본적으로 기기 내부(브라우저 저장소)에만 저장됩니다.
  • 공유 기능 사용 시: 보드를 "공유"하면 해당 보드 데이터가 Google Firebase Firestore(서울 리전)에 저장되어 참여 코드를 아는 기기 간에 동기화됩니다. 이때 익명 인증 식별자(개인을 특정하지 않는 임의의 ID)가 사용됩니다.
  • 위치정보: 지도 기능에서 "현 위치" 사용 시 기기의 위치정보를 이용합니다. 위치는 화면 이동과 지도 기준점 설정에만 쓰이며, 기준점 좌표는 보드 데이터의 일부로만 저장됩니다. 위치 이력을 별도로 수집·전송하지 않습니다.
  • 지도 타일: 지도 표시를 위해 OpenStreetMap 및 Esri 서버에서 지도 이미지를 받아옵니다. 이 과정에서 해당 서비스에 통상적인 네트워크 정보(IP 주소)가 전달됩니다.

2. 수집하지 않는 정보

  • 이름, 연락처, 계정 정보 등 개인 식별 정보를 수집하지 않습니다.
  • 광고 식별자, 사용 통계·분석 도구를 사용하지 않습니다.

3. 보관 및 삭제

  • 기기 내 데이터는 앱(브라우저) 데이터 삭제 또는 보드 삭제로 즉시 제거됩니다.
  • 공유된 보드 데이터는 Firestore에 보관되며, 삭제를 원하시면 아래 연락처로 요청해 주세요. 익명 인증 계정은 30일 미사용 시 자동 삭제됩니다.

4. 제3자 제공

법령에 따른 경우를 제외하고 보드 데이터를 제3자에게 제공하지 않습니다. 데이터 처리 위탁: Google Firebase(데이터 동기화), GitHub Pages(앱 호스팅), OpenStreetMap·Esri(지도 이미지).
