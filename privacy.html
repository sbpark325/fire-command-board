현장지휘 보드 개인정보처리방침

시행일: 2026-08-21

현장지휘 보드(이하 "앱")는 소방 현장 지휘판을 디지털화한 도구입니다. 앱은 회원가입 없이 동작하며, 개인정보 수집을 최소화하도록 설계되었습니다.

1. 수집·저장하는 정보

  • 보드 내용 (사건명, 출동대 배치, 지도 위 그림·표기, 체크리스트, 무전문 송신 기록, 활동 기록): 기본적으로 사용자의 기기 안(브라우저 저장소)에만 저장됩니다.
  • 공유 기능 사용 시: 보드 내용이 실시간 동기화를 위해 Google Firebase(Firestore) 서버에 참여 코드 단위로 저장됩니다. 공유를 해제해도 서버에 마지막 상태가 남을 수 있으며, 삭제를 원하시면 아래 문의처로 참여 코드를 알려주시면 삭제해 드립니다.
  • 익명 식별자: 공유 기능은 Firebase 익명 인증을 사용합니다. 이름·이메일 등 개인 식별 정보는 수집하지 않습니다.
  • AI API 키: 출동지령서 사진 인식 기능에 사용자가 직접 입력한 API 키는 기기의 브라우저에만 저장되며 앱 운영자에게 전송되지 않습니다.

2. 외부로 전송되는 정보

  • 지도 표시: 지도 타일을 불러오기 위해 OpenStreetMap 및 Esri 서버에 일반적인 웹 요청(IP 주소 포함)이 전송됩니다.
  • 주소 검색: 입력한 검색어가 지오코딩 서비스에 전송됩니다.
  • 출동지령서 인식(선택 기능): 사용자가 AI 인식을 선택한 경우에만 지령서 사진이 선택한 제공자(Google Gemini 또는 Anthropic) API로 직접 전송됩니다. 기기 내 OCR을 선택하면 사진이 기기 밖으로 나가지 않습니다.

3. 수집하지 않는 정보

  • 이름, 연락처, 이메일 등 계정 정보 (회원가입 없음)
  • 기기 위치 정보 (GPS 권한을 요청하지 않습니다)
  • 광고 식별자 — 앱에는 광고와 분석(트래킹) 도구가 없습니다

4. 데이터 보관 및 삭제

  • 기기 내 데이터: 앱의 보드 목록에서 보드를 삭제하거나 브라우저 데이터를 지우면 삭제됩니다.
  • 공유 서버 데이터: 문의처로 참여 코드를 알려주시면 지체 없이 삭제합니다.

5. 제3자 제공

앱 운영자는 수집된 정보를 제3자에게 판매하거나 제공하지 않습니다. 위 2항의 전송은 기능 제공을 위한 처리 위탁(Google Firebase, 지도 타일 서버, 사용자가 선택한 AI 제공자)에 한정됩니다.
