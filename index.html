      Gemini API 키 발급 방법

      무료 티어 — 신용카드 없이 구글 계정만 있으면 됩니다 (하루 요청 횟수 제한 있음)

      1. 휴대폰·PC 브라우저에서 aistudio.google.com/apikey 접속 후 구글 계정으로 로그인
      2. "API 키 만들기" 버튼 클릭 (프로젝트를 물으면 새 프로젝트로 진행)
      3. 생성된 키(AIza… 형태)를 복사
      4. 이 앱의 API 설정 화면 → Google Gemini 탭 → API 키 칸에 붙여넣기 → 저장

      키는 이 기기의 브라우저에만 저장됩니다. 키 발급이 안 되면 잠시 후 다시 시도하거나, 키 없이 쓰는 "기기 내 OCR"을 선택하세요.
